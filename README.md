# FunPay Bot — P2P гарант для NFT-подарков

## 📌 Возможности

- 🔐 Создание сделок с уникальным ID
- 👥 Подключение второй стороны по ссылке
- 💰 Мультивалютный баланс (TON, RUB, USD, UAH, Stars)
- ✅ Подтверждение оплаты и передачи администратором
- 📊 Статистика и логи
- 🎁 Автоматический расчет комиссии 30%
- 📨 Логи и профиты в отдельные группы/темы

## 🚀 Запуск на Render

1. Добавь бота в группу и дай права администратора
2. Создай репозиторий на GitHub с этими файлами
3. Зайди на render.com → New Web Service → подключи GitHub
4. Выбери Environment: Docker
5. Добавь переменные окружения:
   - API_TOKEN
   - LOG_CHAT_ID
   - PROFIT_CHAT_ID
   - LOG_THREAD_ID (или оставь пустым)
   - PROFIT_THREAD_ID (или оставь пустым)
   - ADMIN_IDS
6. Нажми Create Web Service

## 🔧 Команды

- `/start` — Главное меню
- `/admin` — Админ-панель
- `/set_requisites` — Установить реквизиты
- `/dealXXX` — Подключиться к сделке
